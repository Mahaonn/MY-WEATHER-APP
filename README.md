# Weather App

## Description

This weather app allows users to get up-to-date weather information for any city in the world. The app uses an API to fetch weather data and displays it in a user-friendly interface.

## Technologies

- **HTML**: Structure of the web page.
- **CSS**: Styling of the web page.
- **JavaScript**: Logic of the application.
- **React**: Framework for building the user interface.
- **Bootstrap**: CSS framework for creating responsive design.
- **API**: Used to fetch weather data.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mahaonn/MY-WEATHER-APP.git
   ```
2. Navigate to the project directory:
   ```bash
   cd MY-WEATHER-APP
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and go to:
   ```
   http://localhost:3000
   ```
3. Enter the name of a city in the search bar and click the "Search" button. The app will display the current weather information for the selected city.

## Project Structure

- `public/`: Static files.
- `src/`: Source code of the application.
  - `components/`: React components.
  - `App.js`: Main component of the application.
  - `index.js`: Entry point of the application.

## API

The app uses the 🌤 SheCodes Weather API (https://www.shecodes.io/learn/apis/weather) to fetch weather data. To use the API, you need to register on the OpenWeatherMap website and obtain an API key.
